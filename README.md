## 怎么读

第一部分先介绍产品背景、价值与场景，第 2 章找到入口，第 3 章就完成一次小任务，第 4 章再按用途认识界面。第 5—14 章按需要回查：改要求、给材料、用成果、处理运行、接账号、对外办事和持续使用。第二部分可从第 1 章直接进入，八章各有任务分组与跳转入口，章末讲换成自己的事要改什么。第三部分是原理选读，解释模型、工具和后台工作。易变的入口、费用和功能状态集中在附录查询。

本书没有注册或操作 Muse，步骤、中文效果和真人试读尚未验证。案例都是别人公开分享的经历，注明作者、来源和本书读取日期，不写成本书亲历；内容充分的媒体报道或转述明确标注来源性质，只有简短转述的原帖线索放在章末。

## 全书怎样展开

| 读者需要 | 章节安排 |
|---|---|
| 从认识到第一次使用 | 第 1—3 章：看用途、找到入口、完成一件小事 |
| 把这件事做好 | 第 4—8 章：找界面、改要求、给材料、用成果、看进度 |
| 让 Muse 接手更多工作 | 第 9—12 章：自己的资料、对外动作、偏好、持续任务 |
| 按设备和问题查询 | 第 13—14 章：多端使用、额度和日常排查 |
| 找适合自己的用法 | 第 15—22 章：八类场景，章内按任务分组 |
| 理解背后如何工作 | 书后原理选读 |

第 3 章用虚构通知演示完整任务；之后各章按需回查，案例可独立选读。
