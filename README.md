## 适合谁与怎么读

面向会用手机和常见 App、没有编程经验的读者。全书规划先帮助所有读者看懂 Muse，再为能合规使用的读者逐步讲解操作。当前地区、价格和入口统一见[开篇现况页](manuscript/now.md)。

本书未注册或操作 Muse，没有实机、中文效果或真人试读记录。官方资料阅读与实际操作分开登记；教学示例不编写 Muse 的回复。[参考来源](参考来源.md)
