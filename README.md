## 怎么读

前面学习发起任务、提供材料、查看结果、接入必要账号和设置提醒。后面可按家庭、出门、购物、工作、学习、创作、求职和小生意选读。入口、费用和常见问题集中在附录。

本书没有注册或操作Muse，步骤、中文效果和真人试读尚未验证。外部使用者的分享会注明作者和来源，不写成本书亲历。
