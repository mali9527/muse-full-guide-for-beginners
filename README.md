## 怎么读

第一部分从概念、入口与界面开始，完整做一次任务，再逐项讲对话、材料、进度、成果、连接、许可、记忆、持续任务、多端使用与日常排查。第二部分可按家庭、出门、购物、工作、学习、创作、求职和小生意选读。易变的入口、费用和功能状态集中在附录查询。

本书没有注册或操作Muse，步骤、中文效果和真人试读尚未验证。外部使用者的分享会注明作者和来源，不写成本书亲历。
